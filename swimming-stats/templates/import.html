Samsung Health automatically syncs to Google Health Connect on Android. Use any of the methods below to push your data to this dashboard.

Manual POST

Tasker can read Health Connect and POST to this server every day at 5 PM automatically.

  1. Install Tasker and AutoHealth plugin from the Play Store.
  2. Create a new Profile → Time → 17:00 every day.
  3. Add a Task with these actions: 
    AutoHealth → Get Exercises
  Type: Swimming (Pool)
  From: %last_sync_time
  To: now

HTTP Request
  Method: POST
  URL: http://YOUR_PC_IP:5000/api/sync
  Body: (AutoHealth JSON output — see README)
  Content-Type: application/json
  4. Your PC and phone must be on the same Wi-Fi network.

Find your PC IP: open a terminal and run hostname -I (Linux) or ipconfig (Windows).

  2. Create a new shortcut:
    • Method: POST

  3. Add it to your home screen or schedule with Tasker.

POST a JSON array to /api/sync:

curl -X POST http://localhost:5000/api/sync \
  -H "Content-Type: application/json" \
  -d '{
    "source": "health_connect",

      "id": "uuid-here",

API Endpoint

Your dashboard exposes a REST API at:

POST http://localhost:5000/api/sync

Full JSON field reference:

{
  "source": "health_connect",    // string
  "workouts": [
    {
      "id":               string,   // HC record UUID
      "startTime":        ISO-8601, // required
      "endTime":          ISO-8601, // required
      "distanceMeters":   number,
      "energyKcal":       number,
      "laps":             integer,
      "avgHeartRateBpm":  number,
      "maxHeartRateBpm":  number,
      "strokeType":       string,   // FREESTYLE etc.
      "poolLengthMeters": number    // 25 or 50
    }
  ]
}

Other endpoints:

  • GET /api/stats — all timelines as JSON
  • GET /api/workouts — paginated workout list
  • GET /api/last-sync — last sync log entry
